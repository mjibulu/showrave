# ShowRave

ShowRave is an event platform for creating events, selling tickets, managing attendees, messaging customers, and checking people in at the door.

Available on the web, iOS, and Android, with support for 30 languages.

## Interactive demo

Try the event flow from creation to check-in directly in your browser.

1. **Create an event** with tickets, extras, seating, and pricing.
2. **Open the event page** and choose tickets or join a waitlist.
3. **Check out** with reserved seats, coupons, and digital tickets.
4. **Create a display picture** from the event.
5. **Message the organiser** or try live support.
6. **Scan the ticket** and test online and offline check-in.

Nothing in the demo is saved or charged.

ShowRave gives organisers the tools to publish and run events while attendees can discover, book, and manage their tickets.

### Discover events

- Search and browse events
- Filter by date, category, location, and format
- View event details, schedules, venues, and organisers
- Save and share events
- Add events to a calendar
- Open venue locations in maps

### Create and manage events

- Create free or paid events
- Run in-person or online events
- Add dates, schedules, venues, media, and event details
- Save drafts and preview before publishing
- Publish public or private events
- Edit and manage events after publishing

### Tickets and seating

- Create multiple ticket types
- Set prices, quantities, and sales periods
- Offer general admission or reserved seating
- Use seat maps
- Track ticket availability
- Issue QR tickets
- Support mobile wallet passes

### Extras

Sell additional items alongside tickets, including merchandise, packages, uniforms, and other event extras.

### Coupons and promotions

- Create event-specific discount codes
- Set coupon values and availability
- Run promotional campaigns
- Review campaign performance

### Checkout

Attendees can purchase multiple ticket types, extras, and reserved seats in one order.

Checkout supports coupons, attendee details, billing information, and digital ticket delivery.

### Orders and tickets

Attendees can view their orders, tickets, invoices, booking status, and admission details from their account.

### Teams

Organisers can work independently or with a team.

- Invite team members
- Assign roles and permissions
- Manage organisation events
- Give door teams access to the events they are scanning

### Finance

Organisers can review:

- Ticket sales
- Fees and earnings
- Transactions
- Payouts
- Bank details
- Sales history

### Reports

Track ticket sales, bookings, revenue, and event performance, with report exports available when needed.

### Messaging

Attendees and organisers can message each other directly.

Messaging includes:

- Direct conversations
- Live support
- Typing indicators
- Read receipts
- Image attachments
- Push and in-app notifications

## How the products work together

1. Create and publish an event with ShowRave.
2. Promote it through event listings, campaigns, and DP Studio.
3. Sell tickets on the web or in the ShowRave app.
4. Support attendees through messaging.
5. Check people in with Ticket Scanner.
6. Review sales and event performance afterward.
